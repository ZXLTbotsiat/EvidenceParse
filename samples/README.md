# Samples

These small, redistributable files are ready for a first local trial of
EvidenceParse. They contain no customer data.

- `demo-invoice.pdf` exercises the invoice workflow.
- `handwritten-style-note.png` exercises generic OCR, slight rotation, ruled
  paper, handwriting-style glyphs, numeric values, and source-region linking.

The handwritten-style note is synthetic. It is useful for demonstrating the
review workflow, but it must not be treated as a benchmark for unrestricted
real-world handwriting.
